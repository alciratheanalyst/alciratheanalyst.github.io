<Limpieza de Datos en SQL>

Descripción del Proyecto

El objetivo principal de este proyecto es realizar un proceso exhaustivo de limpieza y estandarización de datos (Data Cleaning) sobre un conjunto de datos públicos relativo a despidos masivos globales (World Layoffs, alojado originalmente en Kaggle).

Tecnología y Herramientas

  • Motor de Base de Datos: MySQL Server.
  • Lenguaje: SQL
    DDL: Data Definition Language. Definición, modificación o eliminación de la estructura de los objetos dentro de la base de datos
    DML: Data Manipulation Language. Para trabajar con los registros dentro de las tablas sin alterar las estructuras.
  • Técnicas y Funciones de SQL Aplicadas: Creación de Entornos Staging, Funciones Ventana (Window Functions), Manipulación-Limpieza de Texto y Estandarización de Tipos de Datos.
  • kaggle: Layoffs 2022 Dataset

Integridad: Depuración del dataset mediante entornos auxiliares (staging) y funciones de ventana, eliminando duplicados sin alterar los datos originales.
Estandarización: Homogeneización de categorías de industria y nombres de país, asegurando que los agrupamientos futuros arrojen resultados precisos.

Calidad para Análisis Posterior (EDA): Se corrigieron los formatos de fecha y se eliminaron registros sin información clave de despidos. Esto dejó el dataset completamente limpio y listo para el análisis de negocio o su integración en herramientas de BI como Power BI y Tableau.
